# 项目接手说明模板

保存为目标项目的 `docs/project_memory/COORDINATOR_BRIEF.md`，控制在约一页。供协调者理解全局，不代替用户授权或现场验证。

- 更新时间与本轮核实范围
- 项目用途、常用简称、对应子项目
- 本人当前目标与当前主线
- 已有成果：可查看入口、完成证据、哪些只是示例
- 既定决定与不可越过的边界
- 尚未接通、真实阻塞、待本人决定的事项
- 下一段可见成果、验收路径、优先复用哪些已有模块
- 关键依据：少量仓库内相对路径；状态易变项标明需重查

每段成果后更新变化，不追加整段聊天。缺说明时先核已有产物再补；目标只授权只读时先返回说明，不自行落盘。协调者每次读取说明、当前状态、决定及原聊天新证据；被截断的资料不能当成内容不存在。
